# CHR 파일 포맷

쥬라기원시전2의 CHR 파일 오프셋 분석 자료다.

## 이미지 개수 (4바이트)

- 전체 : 0x2210
- 경계 (G) : 0x2214 / 0x2250 (분할)
- 이동 (M) : 0x2218 / 0x2270 (분할)
- 공격 (A) : 0x221C / 0x2290 (분할)
- 죽음 (D) : 0x2220 / 0x22B0 (분할)
- 베리모음 (BG) : 0x2224 / 0x22D0 (분할)
- 베리없이이동 (BME) : 0x2228 / 0x22F0 (분할)
- 베리소지이동 (BMF) : 0x222C / 0x2310 (분할)
- 베리채취없음 (BGE) : 0x2230 / 0x2330 (분할)
- 베리채취있음 (BGF) : 0x2234 / 0x2350 (분할)
- 수리 (REP) : 0x2238 / 0x2370 (분할)

## 사운드 개수 (4바이트)

- 전체 : 0x241C
- 선택 (S) : 0x2424
- 이동 (M) : 0x2428
- 공격 (A) : 0x242C
- 공격보조 (L) : 0x2430
- 죽음 (D) : 0x2434
- 베리모음 (B) : 0x2438
- 물모음 (W) : 0x243C
- 준비 (R) : 0x2440
- 작업완료 (X) : 0x2444

## 파일 구간 오프셋

- CEI : 0x0 ~ 0x24BB
- PNT : 0x24BC ~ 0x28BB
- SPZ : 0x28BC ~ (SPZ 헤더 참조)
- WAV : SPZ 끝 ~ (WAV 헤더 참조)
